# EZ SCAN

EZ SCAN — приложение для буферизации QR-кодов и автоматической отправки их в браузер.

## Возможности

- 📦 Буфер QR-кодов
- ⚡ Автоматическая отправка пачками
- 🎯 Обучение координат мыши
- 🖱 Автоматизация кликов через xdotool
- 📋 Автоматическая вставка QR-кодов
- 👤 Профили настроек
- ⏱ Настраиваемые задержки
- ⌨ Настраиваемые горячие клавиши
- 🗑 Управление очередью
- ⏹ Возможность остановить отправку
- 📖 Встроенная инструкция
- 🔄 Переключение между автоматическим и ручным режимом

## Требования

- Linux
- Python 3
- PySide6
- xdotool
- pyperclip

python3 main.py
