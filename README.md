# EZ SCAN
EZ SCAN — инструмент для автоматизации работы с QR-кодами и производственными рабочими станциями.

EZ SCAN предназначен для производственных и рабочих станций, где необходимо быстро считывать большое количество QR-кодов, временно накапливать их в буфере и автоматически передавать их в другую программу.

# 🖥️ Интерфейс

Главное окно EZ SCAN содержит:

- текущий размер буфера;
- кнопку отправки;
- кнопку остановки;
- кнопку настроек;
- управление автоматической отправкой;
- управление профилями;
- кнопку очистки буфера;
- статус текущей операции.

Пример отображения буфера:

    18 / 24

Это означает, что в буфере находится 18 QR-кодов из максимально допустимых 24.

---

# 📦 Буфер QR-кодов

После сканирования каждый QR-код помещается в буфер.

Например:

    QR-001
    QR-002
    QR-003
    QR-004
    ...
    QR-024

Размер буфера можно изменить в настройках.

По умолчанию:

    Размер буфера: 24
    Размер пачки: 12

---

# ⚡ Автоматическая отправка

EZ SCAN может автоматически начинать отправку после накопления необходимого количества QR-кодов.

Например:

    Размер буфера: 24
    Размер пачки: 12

После получения 12 QR-кодов программа автоматически запускает отправку первой пачки.

Во время отправки новые QR-коды могут продолжать поступать в буфер.

После завершения первой пачки программа может автоматически отправить следующую.

---

# 🎯 Обучение координат

EZ SCAN позволяет самостоятельно обучить координаты элементов интерфейса, с которыми должна работать программа.

В настройках доступен раздел:

    🎯 Тренер

Можно настроить:

- координаты полей ввода;
- координаты кнопок;
- порядок действий;
- добавление новых действий;
- удаление действий;
- изменение порядка действий.

Это позволяет адаптировать программу под разные рабочие интерфейсы без изменения исходного кода.

---

# 🖱 Автоматизация

После получения QR-кодов EZ SCAN может выполнять последовательность действий:

    Сканирование QR
           ↓
    Добавление в буфер
           ↓
    Формирование пачки
           ↓
    Вставка QR
           ↓
    Enter
           ↓
    Нажатие кнопок
           ↓
    Следующий QR
           ↓
    Завершение пачки

Порядок действий настраивается через Тренер.

# ⏱ Тайминги

В настройках можно отдельно изменить задержки автоматизации.

Доступны:

- 🖱 задержка после клика;
- 📋 задержка после вставки QR;
- ↵ задержка перед Enter;
- ⏳ задержка перед кнопками;
- 🔘 задержка между кнопками;
- 📦 задержка после пачки;
- ⏱ задержка после кнопок;
- 🔄 задержка между пачками.

Это позволяет настроить EZ SCAN под скорость конкретного рабочего интерфейса.

EZ SCAN поддерживает несколько профилей.

Каждый профиль может иметь собственные:

- размер буфера;
- размер пачки;

# ⌨ Горячие клавиши

Горячие клавиши можно изменить в настройках.

По умолчанию:

    F1 — Отправить
    F2 — Стоп
    F3 — Очистить
    F4 — Авто
    F5 — Настройки
    F6 — Профиль

Все клавиши можно переназначить.

# 📷 QR-сканер

При запуске программа автоматически ищет подключённый сканер.

Поддерживается работа со сканерами, которые определяются Linux как клавиатурные устройства.

Например:

    /dev/input/by-id/usb-Scanner_Scanner_20230429-event-kbd

При первом запуске программа может выполнить первоначальную настройку доступа к устройству.

---

# 🛠️ Первоначальная настройка

При первом запуске EZ SCAN открывает мастер первоначальной настройки.

Он позволяет:

- проверить наличие QR-сканера;
- определить устройство;
- проверить доступ к сканеру;
- выполнить необходимые настройки;
- подготовить программу к работе.

После завершения настройки программа сохраняет результат и при следующих запусках обычный мастер больше не требуется.

    Проверка обновлений: включена
    Интервал: 24 часа

# 📦 Установка

EZ SCAN распространяется в виде AppImage.

Скачайте последнюю версию из GitHub Releases.

Например:

    EZ SCAN-v2.1-x86_64.AppImage

Сделайте файл исполняемым:

```bash
chmod +x EZ SCAN-v2.1-x86_64.AppImage
```
Запустите:

```bash
./EZ\ SCAN-v2.3-x86_64.AppImage
```
# 🐧 Linux
Поддерживаемый формат:

AppImage

Python для пользователя устанавливать не требуется.

Основные Python-зависимости уже находятся внутри AppImage.

В состав сборки входят:

* Python;
* PySide6;
* evdev;
* pyperclip;
* файлы EZ SCAN.

# ⚙️ Требования
Для готового AppImage

Не требуется:

* установка Python;
* создание virtualenv;
* установка PySide6;
* установка evdev;
* установка pyperclip.

Необходима Linux-система с поддержкой AppImage.

Для работы со сканером пользователь должен иметь необходимые права доступа к /dev/input.

# 🔐 Права доступа к сканеру

Если Linux запрещает доступ к QR-сканеру, необходимо добавить пользователя в группу input.

Например:
```bash
sudo usermod -aG input $USER
```
После этого необходимо выйти из системы и войти снова.

Проверить устройство можно:
```bash
ls -l /dev/input/by-id/
```

# 🚀 Использование
1. Запустите EZ SCAN

Запустите AppImage:
```bash
./"EZ SCAN-v2.3-x86_64.AppImage"
```

При первом запуске появится первоначальная настройка.

2. Подключите QR-сканер

Подключите сканер к компьютеру.

Программа автоматически определит устройство.

После успешного обнаружения появится сообщение о готовности сканирования.

3. Сканируйте QR-коды

Наведите сканер на QR-код.

После сканирования код появится в буфере.

Например:

* 1 / 24
* 2 / 24
* 3 / 24
  
4. Автоматическая отправка

Если включён режим:

⚡ Авто: ВКЛ

при достижении размера пачки программа автоматически начнёт отправку.

5. Ручная отправка

Если автоматическая отправка выключена, нажмите:

▶ Отправить
6. Остановка

Для остановки текущей отправки:

⏹ Стоп

или используйте горячую клавишу:

F2

7. Очистка

Для удаления всех QR-кодов из буфера:

🗑 Очистить
или:
F3

# 💾 Конфигурация

Пользовательские настройки сохраняются отдельно от программы.

Конфигурация находится:
```bash
~/.config/EZ SCAN/config.json
```

Это позволяет обновлять саму программу без потери:

* профилей;
* координат;
* таймингов;
* горячих клавиш;
* размера буфера;
* настроек автоматической отправки.

При обновлении AppImage пользовательская конфигурация не удаляется.

```bash
source venv/bin/activate
```

```bash
pip install PySide6 evdev pyperclip
```

```bash
python3 bootstrap.py
```

# 📦 Сборка AppImage

Для создания готового AppImage используется:
```bash
build_appimage.sh
```
Запуск:
```bash
chmod +x build_appimage.sh
```
Затем:
```bash
./build_appimage.sh
```
Готовая сборка появится в:
```bash
dist/
```
Например:
```bash
dist/EZ SCAN-v2.3-x86_64.AppImage
```
